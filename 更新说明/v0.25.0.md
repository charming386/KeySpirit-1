# v0.25.0 —— 战斗详情新增「回合流水」：每一回合双方打了多少、谁暴击了

> 起因：「加一个功能，战斗详情界面要显示每个回合我方和敌方的伤害（包括基础伤害和暴击等附加伤害）和受到的伤害」

## 一、记什么

战斗本来每 2 秒结算一回合（`ResolveRound`）：玩家先打一刀，怪没死就反击一次。以前这一回合的结果除了血条变化，什么都没留下。现在每回合留一条记录：

| 字段 | 含义 |
|---|---|
| `No` | 这一只怪打到第几回合（换怪回 1） |
| `Base` | 基础伤害 = `玩家攻击 − 怪防御 × 0.5`（下限 1） |
| `Crit` | 暴击**附加**的那部分（`dmg × 暴伤`），没暴击就是 0 |
| `Taken` | 这一回合我方承受 = `怪攻² / (怪攻 + 我方防御 × 6)`（下限怪攻 2%） |
| `Killed` | 这一刀打死了（怪没机会反击） |

总伤害 `Dealt = Base + Crit`。

## 二、为什么必须拆开「基础」和「暴击」

只给一个总数的话，「这一刀打了 8 倍」是暴击还是这一只怪防御低，玩家分不出来——**前者是运气，后者是配装，是两件事**。拆开之后：

```
#2  1.18K +590      42
#3  1.18K           42
```

`+590` 一眼就知道是暴击多打的；同一只怪后面几行都是 1.18K，说明那一刀确实是运气。

## 三、界面怎么显示

「战斗详情」页在「我方攻防」下面新增一段，共 8 行固定高度：

```
回合流水 · 最近 8 回合
回合   对怪（基础 + 暴击）      受击
#1     1.18K                    42
#2     1.18K +590               42      ← 附加是橙色，和基础的白字分开
#3     1.18K                    42
#6     1.18K                    打死    ← 这一刀打死了，没有反击
▸#1    1.31K                    47      ← 换了一只，号回到 1
```

三个细节：

- **打死的回合写「打死」不写「受 0」**。那一刀怪没有反击，`0` 会被读成「怪打我 0 血」，是另一回事。
- **换怪时回合号回 `#1`，前面加 `▸`，但旧记录不清空**。理由见下一节。
- 行数固定 8 行（含空行保持占位），不随后续回合增删——**动态增删会让子列高度每次换怪跳一下，窗口跟着抽**。

## 四、顺手修掉一个会「吃掉最后一刀」的问题

原本的打算是「换怪就清空流水」，因为这一页上方全是「这一只 / 我方」。写完自测才发现这条路走不通：

```
ResolveRound → 记录这一刀（Killed=true）→ KillMob → SpawnMob → 清空
```

**记录和清空发生在同一帧**，玩家永远看不到「打死那一刀」。自测里 300 回合只留下 185 条，少掉的 115 条全是被打死那只的最后一下。

现在改成：换怪**不清空**，只把回合号重置为 1；靠 8 条上限自然顶掉旧的。只有「初始化重置 / 转生」这种真正的重开才 `Clear()`。这样玩家能看到 `…#6 · ▸#1 · #2` 这种过渡，最后一刀也不会凭空消失。

## 五、自测

193 → **199 项**，新增六条：

- 基础 + 暴击附加 = 总伤害，且基础恒为正（样本 300 条）
- 暴击附加只在暴击回合出现且必为正（暴击 7 条 / 不暴击 293 条）
- 没打死的那一回合一定有反击伤害（受击 > 0）
- 打死那一刀不受反击（受击 = 0）——用反射把怪血压到 1，连打 40 次验证
- 只保留最近 8 条
- 换怪后保留上一只的最后一刀，新一只回合号从 1 重新数

顺带确认了一件事：`CritRateBase = 2%`，所以**墨眸 0 级也不是 0% 暴击**。第一版断言写的是「关掉墨眸就不该有暴击」，跑出来直接 FAIL——这不是代码错，是断言错，已改成「有附加 ⇔ 判为暴击、附加必为正」，不再假设任何一边。

## 六、影响范围与开销

- `Core/Game.cs`：新增 `RoundHit` 记录、`RoundHits` 只读列表、`RoundLogMax = 8`；`ResolveRound` 记录一回合；`SpawnMob` 重置回合号；`ResetFight` 清空。
- `UI/PanelWindow.cs`：`BuildBattle` 增加一段 8 行；每行三个 `TextBlock`（基础 / 暴击附加 / 受击），按 `rows` 的每秒 Tick 刷新。
- 性能：每回合多一次 `List.Add`（超过 8 条时 `RemoveAt(0)`，8 元素列表可忽略），记录本身是结构体，不额外分配。战斗数值、存档格式、推层曲线一律没动。

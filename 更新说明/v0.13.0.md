# 键灵 v0.13.0 发布说明

| 项目 | 内容 |
| --- | --- |
| 版本号 | 0.13.0 |
| 发布日期 | 2026-11-10 |
| 版本性质 | 机制与数值重做（含上一版 v0.12.3 的全部修复） |
| 运行平台 | Windows 10 / 11（x64） |
| 分发形式 | 免安装绿色版，自包含单文件，无需预装 .NET |

## 一、概述

这一版动三条底层数值，三条都是「属性看起来在长，实际没起作用」的问题：

- **墨眸的暴伤从线性改成指数** —— 原来是指数成本买线性收益，喂满 300 多级只换 ×1.24 期望伤害；
- **怪物打玩家从减法减伤改成软曲线** —— 原来防御一超过怪攻两倍，受伤被压在 1 血，力竭机制整个作废；
- **精英/守层者的经验倍率随层数放大** —— 原来几千层要给 23 只精英才升一级，对不上「两三只精英一级」的设计口径。

## 二、墨眸：暴伤改指数

| | v0.12 | v0.13 |
| --- | --- | --- |
| 暴击率 | `min(60%, 2% + 0.15%×级)` | 不变 |
| 暴伤 | `0.5 + 封顶后溢出的暴击率×1`（线性） | **`0.5 × 1.06^级`（指数）** |
| 100 级期望伤害 | ×1.09 | ×29.8 |
| 304 级期望伤害 | ×1.24 | ×1.17e+07 |

原来那套的问题很直接：另外三件每级都是 ×1.06 的**指数**，只有暴伤是**线性**，而成本同样是 ×1.07。同一笔墨晶的期望伤害回报，投墨眸只有投墨刃的 **1/68** —— 指数成本买线性收益，这条线必然是废属性。

改成指数后，暴击率封顶时期望伤害 = `1 + 0.6 × 暴伤`，与暴伤同阶；而暴伤与墨刃同速（都是每级 ×1.06、成本 ×1.07），**两件本命器的边际收益终于对齐**，不再有「只能喂墨刃」的唯一答案。前期（暴击率还低）墨眸仍略弱，靠暴击的随机性补，不会在第 1 层就碾压。

面板上的暴伤改用**倍率**显示（`×1.5` → `×24.0M`），不再打成 `280000000000%` 这种读不了的数字。

## 三、防御：减法减伤 → 软曲线

| | v0.12 | v0.13 |
| --- | --- | --- |
| 玩家受伤 | `max(1, 怪攻 − 防御×0.5)` | `max(怪攻×5%, 怪攻² ÷ (怪攻 + 防御×3))` |

旧公式有两个死结：

1. **防御超过怪攻两倍后，受伤被 clamp 成 1 血/回合**。血量上亿也打不完一只怪，力竭 → 休整 120 秒 → 自动回退这套机制在中期彻底作废，墨衣和墨印一起变成废属性。
2. **怪攻一涨过阈值，伤害立刻从「1」跳到「按亿计」**，两回合把人打死，中间没有任何过渡带。减法减伤遇到两边都在指数增长，跨阈值必然断崖。

新公式没有阈值：防御 = 怪攻时受伤 = 攻击/4（减伤 75%），防御是怪攻 10 倍时 ≈ 攻击/31，防御趋 0 时 ≈ 全吃（与旧公式一致）。**5% 下限是故意留的**——防御再高也总会掉一点血，力竭机制必须一直活着，否则「扛得住就永远不用休整」会从另一头让这套机制失效。

玩家打怪仍然用减法（`攻击 − 防×0.5`）：玩家的攻击是指数涨的，减法是「够强就秒」，手感更干脆。两边不对称是有意的。

## 四、精英与守层者的经验倍率

| | v0.12 | v0.13 |
| --- | --- | --- |
| 精英经验 | ×1.5（固定） | `max(1.5, k×0.5)` |
| 守层者经验 | ×3（固定） | `max(3, k)` |

`k` = 当层「升一级要打几只小怪」= `2 + 0.58×√层`。改完的效果：

| 层 | 打几只小怪一级 | 打几只精英一级 | 守层者 |
| --- | --- | --- | --- |
| 1 | 2.6 | 1.7 | 3 只一级 |
| 100 | 7.8 | 2.0 | 1 只一级 |
| 386 | 13.4 | 2.0 | 1 只一级 |
| 3,000 | 33.8 | 2.0 | 1 只一级 |
| 9,999 | 60.0 | 2.0 | 1 只一级 |

「2 只精英 = 一级」「1 只守层者 = 一级」在 100 层以后是恒定的，低层不加成（保住「打两只小怪升一级」的前期手感）。

**金币倍率不动**，仍是 ×1.5 / ×3 —— 金币是经济，经验是节奏，两件事不该共用一套倍率。

副作用：一层（9 小怪 + 1 精英 + 1 守层者）的经验当量从 12.5 涨到 59.7（3000 层），每层约升 1.8 级而不是 0.4 级。9,999 层通顶时的等级由约 4,100 级提到约 17,700 级，等级乘区从 ×63 到 ×267 —— 有分量，但仍追不上每层 6% 的指数，等级依旧是「缓线」。

## 五、对现有存档的影响

存档结构未改动，可直接覆盖安装。三件事值得知道：

- **你的墨眸等级会一次性变强很多**。按 304 级算，期望伤害从 ×1.24 变成 ×1.17e+07，一回合能打穿的层数从 354 提到 630。但这**不会让你直接冲上去**——卡住你的一直是防御，不是输出：381 层每回合掉 4.8e7、能撑 700 多回合，420 层就只剩 34 回合，440 层 7 回合。实际推进大约 +30~40 层，然后在上层同样被防御卡住。这是版本切换的一次性红利，跟「老存档等级不压缩」同一性质。
- **防御变成真属性了**。以前防御够了就是 1 血/回合、永远不死；现在防御越高受伤越少，但**永远在掉血**，高层还是会被力竭送回休整。墨衣、墨印的强化终于有意义。
- **升级会快一点**（每层从 0.4 级到 1.8 级），但单只小怪仍然只给约 3% 的一级经验，不会回到「打一只怪升一级多」的旧状态。

## 六、本版同时包含上一版（v0.12.3）的全部修复

- 强化页的属性预览漏算等级乘区与墨根乘区（强化页说 3.0B、角色页说 35.0B）；
- 「锁定本层」与「自动下潜」从未真正生效（打完守层者无条件推进下一层），两个开关改为联动，驻守时「自动回退」置灰；
- 驻守时打赢守层者不再丢「本轮最高」；
- 自动回退判的不是「连败」（计数打赢后没清零）；
- 转生 / 初始化重置残留敲击掉袋进度；
- 墨眸封顶后面板仍显示 60% 以上暴击率（面板自己重算了一遍公式，漏了封顶）。

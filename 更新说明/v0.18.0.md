# v0.18.0 —— 生命与防御不再吃等级乘区

> 起因：「生命值会不会单次增加的量也太多了？比如现在怪物攻击力和玩家生命值之间差了几个数量级」

## 一、问题：不是 +6% 太多，是多乘了一个没人竞争的乘区

墨衣每级 +6%，墨刃也是 +6%，两条线的成长率本来就一样。真正的问题在这里：

| 项目 | 619 层实测 | 说明 |
|---|---|---|
| 玩家生命 | 7.09e+16 | 墨衣 540 级 |
| 怪物攻击 | 7.47e+13 | |
| **生命 / 怪攻** | **949 倍** | 差 3 个数量级 |
| 单级墨衣给的血 | 4.5e+15 | **= 60 只怪的攻击力** |
| 单级墨刃给的攻击 | — | = 1.1% 只怪血 |
| 一条命能撑 | 1.9 万回合 | **≈ 258 层**才力竭一次 |

949 倍是两个因数乘出来的：

| 来源 | 倍数 | 为什么是漏洞 |
|---|---|---|
| 墨衣 1.06^540 对怪攻 1.05^618 | 49.5× | 每层漂移 0.95%。墨刃也是 1.06，但它追的是怪血 1.06，刚好抵消；只有生命侧没有对手 |
| 生命额外乘 `1+0.015×(Lv−1)` | 20.3× | 等级乘区**只作用于玩家**，怪攻一点不吃。攻击侧这 20 倍是必需的（否则升级不能推进），生命侧纯白送 |

连带的两个死掉的系统：

- **力竭 / 休整 / 自动回退 / 休整倒计时 / 力竭率表**：要 1.9 万回合才触发，等于从未运行过；
- **墨印（防御）**：5.65e+15 防御 = 怪攻的 67 倍，理论伤害只剩 0.44%，被 5% 地板整个盖住 —— 从约 200 层起**每级收益为 0**，而它是四件里第二贵的（1.15 倍）。

## 二、改动

```
旧  玩家 HP   = (基础血 + 墨衣×1.06^lv) × (1 + 0.015×(Lv−1)) × 1.06^墨根
新  玩家 HP   = (基础血 + 墨衣×1.06^lv) × 1.06^墨根                 ← 摘掉等级乘区，基础值 80 → 120

旧  玩家 防御 = (基础防 + 墨印×1.06^lv) × (1 + 0.015×(Lv−1)) × 1.06^墨根
新  玩家 防御 = (基础防 + 墨印×1.06^lv) × 1.06^墨根                 ← 摘掉等级乘区

旧  受伤 = max(atk² / (atk + def×3), atk × 5%)
新  受伤 = max(atk² / (atk + def×6), atk × 2%)
```

四个常数各有理由，不是凑的：

| 改动 | 理由 |
|---|---|
| 生命摘乘区 | 949 → 74 倍，一条命 258 → 24 层。1 层、50 层完全无感（那时乘区 ≈ 1） |
| 防御摘乘区 | 67 → 3.7 倍，地板不再盖住墨印。**不摘防御就只解决了半个问题**：伤害仍被 5% 地板兜住，墨印照样是死属性 |
| 墨衣基础 80 → 120 | 防御摘掉后伤害变高，血池要跟着抬一点，把一条命拉回 10~20 层 |
| 系数 3 → 6、地板 5% → 2% | 防/怪攻落在 1.0~3.3 时，5% 地板会在 4.8% 处正好咬住，墨印的边际收益又归零；下限降到 2%（最多减伤 50 倍）才留出「还能再练几十级」的空间。系数 3→6 是补偿中期的：防/怪攻 ≈ 1 时若仍按 75% 减伤，每回合掉 25% 怪攻，一条命只剩 4 层 |

**攻击不动**：它吃等级乘区是要跟「怪血 = 50 × 1.06^层」赛跑，没有那 20 倍升级就没有意义。生命和防御的问题是**乘区没有对手**，不是乘区本身错。

## 三、效果（按玩家真实档 + 同比例外推）

| 层 | 生命 | 防/怪攻 | 每回合掉血 | 一条命层数 | +1 级墨印 |
|---|---|---|---|---|---|
| 10 | 5.0e+2 | 2.12 | 7.3% | 43 | −0.1pp |
| 100 | 2.1e+4 | 1.04 | 13.8% | 9.6 | −0.6pp |
| 200 | 3.0e+6 | 1.15 | 12.6% | 10.8 | −0.6pp |
| 400 | 7.7e+10 | 1.89 | 8.1% | 16.1 | −0.4pp |
| 619（当前） | 5.2e+15 | 3.32 | 4.8% | 20.0 | −0.3pp |

一条命从 258 层收回到 10~20 层，墨印每级都能看到掉血下降。10 层前后一条命 40 多轮一层，是新手期的「不容易死」，符合预期。

## 五、存档

**不需要迁移，Schema 仍是 3**。生命上限与防御都是按强化等级实时算出来的，不进存档：读档后新数值立刻生效，不需要改任何字段。

副作用是打开就会看到：生命从 7.1e+16 变成 5.2e+15、防御从 5.7e+15 变成 2.5e+14，血条比例不变（当前血量上限一起重算）。**这是预期内的数字缩小，不是掉档。**

# v0.18.1 —— 怪物的攻击再也追不上自己的血：怪攻指数 1.05 → 1.0515

> 起因：「怪物的攻击力会不会太低了？跟血量不匹配」（附图：620 层 · 残页魇 · 生命 2.4e+17 / 攻击 73.7T / 防御 187.3M）

## 一、确实不匹配，而且不匹配的方式比看上去更严重

| 项目 | 面板 | 实算（含种类倍率） |
|---|---|---|
| 怪物生命 | 2.4e+17 | 2.31e+17（残页魇 ×1.06） |
| 怪物攻击 | 73.7T | 7.37e+13（×0.94） |
| 怪物防御 | 187.3M | 1.87e+8 |
| **怪血 / 怪攻** | — | **2944 倍** |

对照自己：生命 9.94e+15、攻击 4.08e+16（含暴击期望 5.4e+16）、防御 2.78e+14。所以

> **玩家一刀 ≈ 怪物攻击 520 次的伤害。**

## 二、根因：两条指数曲线不同速

```
怪血 50 × 1.06^(层−1)      每层 +6.00%
怪攻  6 × 1.05^(层−1)      每层 +5.00%
```

每层差 0.95%，619 层累积 **348 倍**，再乘基础比 50/6 = 8.3 → 1 层时 8:1（正常），620 层 2944:1。

`1.05` 这个值不是随手写的：攻击这条线唯一的对手是玩家生命 `120 × 1.06^墨衣等级`，而墨衣等级永远落后层数约 10%（620 层时 550 级），所以「生命 / 怪攻」实际按 `1.06^0.887 / 1.05` 演化——**跑得比怪攻快**。这就是下面这条的反常。

## 三、真正的病：越往深处越安全

| 层 | 100 | 200 | 400 | 620 | 900 |
|---|---|---|---|---|---|
| 一只怪几回合 | 1.5 | 1.5 | 2.1 | 4.3 | 12.1 |
| **一条命能撑几层** | 12.8 | 15.8 | 34.6 | **54.7** | **85.9** |

620 层要挨 **2826 回合**才力竭，约合 2.3 小时一次。力竭 → 休整 120s → 三连败自动回退这条链，在 400 层之后基本不触发；面板上的休整倒计时、图标状态也长期不出现。顺带，**墨印会在约 1200 层撞回 2% 地板**，v0.18.0 刚修好的「每级 0 收益」换个楼层会复发。

## 四、改法

```csharp
public const double MobAtkExp = 1.0515;      // 原 1.05
public static Big MobAtk(int n) => Big.Clamp(Big.Pow(MobAtkExp, n - 1) * (6 * MoChao(n)));
```

只改一个常数。**怪血 1.06 / 怪防 1.03 / 金币 1.06 / 经验 1.05 全部不动。**

效果（620 层）：

| 项目 | 改前 | 改后 |
|---|---|---|
| 怪物攻击 | 7.84e+13 | **1.78e+14**（×2.3） |
| 怪血 / 怪攻 | 2944 倍 | **1372 倍** |
| 玩家攻击 / 怪攻 | 520 倍 | **229 倍** |
| 生命 / 怪攻 | 127 倍 | **55 倍** |
| 防御 / 怪攻 | 3.55 倍 | **1.54 倍** |
| 一条命 | 2826 回合 ≈ 54.7 层 | **565 回合 ≈ 10.8 层** |

一条命层数曲线由 `12.8 → 15.8 → 34.6 → 54.7 → 85.9` 改为 `9.9 → 9.3 → 11.7 → 9.9 → 7.0`，**单调向下**，符合「越深越难」。墨印归零节点从 1200 层推到 2000 层之后。

前期完全无感：1 层 1.0515⁰ = 1（一个数字都没变），10 层只高 1.4%，50 层 +7%。

## 五、两个没选的方案与原因

| 方案 | 结果 | 为什么不用 |
|---|---|---|
| 怪攻指数直接对齐 **1.06** | 620 层怪攻 2.3e+17（现在的 3000 倍） | 墨衣 550 级与层数差 70 级 = 56 倍劣势，玩家 **0.3 回合**躺 |
| 只抬基础值 **6 → 20** | 620 层一条命 5.4 层 | 1 层的一条命从 14 层掉到 **1.6 层**，前期直接卡死 |

也考虑过把怪防从 1.03 提上来（它现在 187.3M 相对玩家攻击 4e+16 等于 0，纯装饰），但试算 1.06 会让 900 层的「每只怪回合数」从 12 涨到 81，直接卡死推进；1.045 以下又仍是装饰。**这一版不动它**，留作以后单独处理。

## 六、做不到的一件事

**「怪血 / 怪攻」这个比值会一直涨**（2944 → 1372 只是慢了一半），因为怪血要跟玩家攻击（1.06^墨刃）赛跑、怪攻要跟玩家生命（1.06^墨衣）赛跑，而这两条线的斜率天生不同。它**不参与任何战斗计算**——一场战斗只由「怪血 / 玩家攻击」和「怪攻 / 玩家生命」两个比值决定。要让它在面板上恒定，得让攻击与生命同速成长，那是另一场改。
